# Support

This repository is not yet a usable integration. For help with the existing integration, consult its [documentation and support channels](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus).

For questions or compatibility conversations about this project, use [Discussions](https://github.com/omerfaruk-aran/esphome-samsung-hvac/discussions). For reproducible defects or actionable proposals, search existing reports and use the appropriate [issue form](https://github.com/omerfaruk-aran/esphome-samsung-hvac/issues/new/choose). Include versions, equipment models, and sanitized configuration and logs where relevant. Never publish credentials or personal information.

For security concerns, follow [SECURITY.md](SECURITY.md). Community support is provided on a best-effort basis.
