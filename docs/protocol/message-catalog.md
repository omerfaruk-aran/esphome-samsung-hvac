# Machine-readable message catalog

components/samsung_hvac/message_catalog.json is a version 1 catalog. catalog.py implements a strict standard-library Python schema plus wire/evidence checks; no new ESPHome runtime package is required. Tests reject missing/extra keys, duplicate IDs, code/type/length conflicts, nonfinite/zero conversions, invalid raw bounds and malformed evidence. JSON nonfinite constants are rejected. The legacy inventory remains a separate source-label record, not executable support data.

Each entry explicitly declares protocol, code, value_type, payload_length, source/destination roles, direction, access, unit, scale, offset, signedness, sentinels/sentinel_status, optional raw_range/valid_values, protocol conversion/layout, device_scope/models, evidence_level, source_url, capture_reference, test_reference, notes and fsv marker. Required fields cannot silently default. Sentinels/valid values/ranges are checked against wire width. Raw sentinel comparison precedes signed/physical conversion. A passive entry must have source/test/scope evidence; observed/confirmed additionally require model/capture references. Software checks structural evidence completeness, not the truth of a hardware claim; maintainers must review actual captures.

Current enabled entries are INFERRED from pinned MIT legacy6b1966bea8db9344d23763454f9cebed015d15c5 and nasactl629c43fce1c6a0595b5070028e34cf4ad0f25386. No actual capture/model verification is recorded. The data re-expresses independently inspected protocol facts and preserves source links; no third-party implementation source is transplanted. Common mappings and signedness limitations are detailed in ac-profile-mappings.md and ehs-mappings.md. Units/types are observations, not write ranges or official Samsung specifications.

NASA scalar type bits determine Enum8, Variable16, LongVariable32 or opaque Structure. Structures must stay disabled as numeric entities. Non-NASA entries describe Cmd20 payload byte/mask/shift and distinguish encoded temperature8 from bit extraction. Temperature conversion is piecewise: bit 7 clear raw−55°C; set ((raw&127)−32)×5/9°C. Its raw encoding is unsigned despite a potentially negative physical result. This metadata does not share NASA state or enable generic Non-NASA entities. Existing Non-NASA profiles perform their own conversions.

FSV upper/lower heating outlet limits 0x424E/0x424F and cold/warm outdoor curve values 0x4254/0x4255 are passive observations only. No FSV polling or write limits are inferred from another project's writable configuration. Catalog access has only passive/disabled values; write is invalid. Disputed 0x4203/4204/42D6 named entries stay UNKNOWN/disabled. Explicit raw observations may inspect those words without a semantic label; see advanced-messages.md.

Test references: tests/test_catalog.py, tests/test_config.py and tests/cpp/test_messages.cpp; synthetic passive FSV fixture metadata under tests/fixtures/advanced. No source/model report is silently promoted to OBSERVED/CONFIRMED. Hardware NOT TESTED.
