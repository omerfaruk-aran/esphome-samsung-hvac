## Findings requiring regression tests

- NASA LongVariable decode is big-endian while encode emits least-significant byte first ([components/samsung_ac/protocol_nasa.cpp:227](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/protocol_nasa.cpp#L227), [components/samsung_ac/protocol_nasa.cpp:269](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/protocol_nasa.cpp#L269)). Record as a source discrepancy, not a verified device defect.
- Message payload lengths and structure fixed-buffer bounds need independent adversarial tests; outer-frame CRC validation does not establish inner payload safety.
- Mutable global protocol selection, parser packets and Non-NASA queues do not provide multi-bus isolation. Do not mechanically transplant them.
- A helper named `variable_to_signed` uses a 65535 threshold; explicit int16 boundary tests are required ([components/samsung_ac/protocol_nasa.cpp:51](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/protocol_nasa.cpp#L51)).
- 0x4203/0x4204 meanings, 0x42D6 Zone 2, Water Law and FSV write safety lack identified-device capture evidence here. Keep disabled/UNKNOWN.
- Existing source does not establish a universal sentinel policy. Missing/invalid-value handling remains UNKNOWN.
