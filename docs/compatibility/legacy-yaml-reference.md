## Schema behavior

- Root `samsung_ac` is `MULTI_CONF = False`, depends on UART and autoloads sensor, binary_sensor, button, switch, select, number, climate and text_sensor ([components/samsung_ac/__init__.py:44](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L44)).
- `devices` is required and coerced to a list. Device `address` is a string. The runtime treats two characters as Non-NASA, otherwise NASA ([components/samsung_ac/protocol.cpp:118](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/protocol.cpp#L118)). Malformed and duplicate addresses require regression coverage.
- The root inherits `uart_id` and polling `update_interval`, default `30s` ([components/samsung_ac/__init__.py:447](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L447)). `flow_control_pin` is optional. Example framing is 9600, EVEN, default 8 data/1 stop bit; this is example evidence, not universal hardware compatibility.
- Capabilities default to fan modes/turbo enabled, horizontal/vertical swing and medium spelling disabled. A device capability block replaces the root block rather than deeply merging it ([components/samsung_ac/__init__.py:468](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L468)).
- Presets: sleep=1, quiet=2, fast=3, longreach=6, eco=7, windfree=9, disabled by default; may supply enabled/name/value. `None`=0 is added when a preset is enabled ([components/samsung_ac/__init__.py:144](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L144), [components/samsung_ac/__init__.py:502](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L502)).
- Custom numeric sensors require `message` and default `type: sensor`; custom binary sensors require `type: binary`. Entity options/filters are ESPHome fields. Water temperature defaults to 0x4237 and signed int16 ×0.1 raw filters; humidity defaults to 0x4038 ([components/samsung_ac/__init__.py:202](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L202)).
- `filter_reset`, `silence_mode`, `filter_warning` and `defrosting` reject two-character addresses ([components/samsung_ac/__init__.py:261](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L261)). Other NASA-specific device restrictions are not comprehensively validated.
- Target number: 16–30 °C step 1; DHW target: 30–70 °C step 0.5; outlet target: 15–55 °C step 0.1. These are legacy UI ranges, not verified safe ranges for arbitrary devices ([components/samsung_ac/__init__.py:617](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L617)).
- Mode choices: Auto/Cool/Dry/Fan/Heat. Water heater: Eco/Standard/Power/Force ([components/samsung_ac/__init__.py:644](https://github.com/omerfaruk-aran/esphome_samsung_hvac_bus/blob/6b1966bea8db9344d23763454f9cebed015d15c5/components/samsung_ac/__init__.py#L644)).
- MQTT debug defaults to disabled by empty host; credential defaults are empty. This inventory contains no real credentials. Debug settings must not be carried forward as public credentials.
